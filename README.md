# **Sonfive's Pokermon+**
This is an add-on mod for InertSteak's Pokermon mod. This mod aims to implement features that I personally believe could be a part of the Pokermon mod. I try to not make things overpowered and aim to keep things balanced whilst still being a lot of fun! 



## Decks

| Name         | Base Effect   |
| ------------- | ------------- |
| Virtuous Deck  | Start with Timer Ball  |
| Shiny Deck | -1 Boosters in shop, Shiny Tag after beating Small or Big Blind |
| Void Deck | Negative Energy cards give +1 Energy Limit, <br/> Rerolls have a 1 in 15 chance to add a Nightmare to shop |
| Rogue Deck | Start with a Mega Stone, <br/>+4 Ante win requirement |
| Pearlescent Deck | -1 Energy <br/>-1 Energy Limit<br/>$1 per de-energized Joker at end of round |


## Stakes

| Name         | Base Effect   |
| ------------- | ------------- |
| Lilac Stake  | Shop can have Weakened Jokers  |


## Consumables

Consumables can be toggled on/off in the mod config options

| Consumable | Effect |
| ---------- | ------ |
| Timer Ball | Create a Pokemon of increasing rarity the longer you wait to use  <br/>this item |
